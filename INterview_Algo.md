⭐ My Interview Pattern Shortcut

Whenever you see a problem, ask these questions:

Question	Think About
Is it a continuous subarray/substring?	                        Sliding Window or Prefix Sum
Is the array sorted?	                                          Two Pointers or Binary Search
Is it asking for frequency/duplicates?	                        HashMap / HashSet
Is it asking for maximum/minimum of a window?	                  Sliding Window
Is it asking for pairs/triplets?	                              Pointers / HashMap
Is it asking to search in a sorted array?	                      Binary Search
Is it asking for previous/next greater?	                        Stack
Is it asking to reverse or detect a cycle in a linked list?	    Linked List (Fast & Slow Pointers)
